# Contributing to Awesome DSA

Thank you for considering contributing to **Awesome DSA**! We welcome high-signal suggestions, fixes, and additions that elevate this list beyond generic link dumps.

---

### Contribution Guidelines

To maintain exceptional quality, please follow these principles when proposing changes:

1. **High Signal & Quality**:
   - Only propose tools, visualizers, papers, or resources that you have personally used and found exceptional.
   - Avoid generic tutorials, affiliate links, and commercial paywalled bootcamps.

2. **Format Standard**:
   - Follow the established item format:
     ```markdown
     * [Resource Name](URL) - Short 1-2 sentence description explaining WHY it's awesome and what makes it distinct.
     ```
   - Ensure the description uses proper punctuation and grammar.

3. **Link Integrity**:
   - Verify that all URLs resolve (no 404s, redirects, or insecure HTTP where HTTPS is supported).
   - Use direct canonical URLs instead of link shorteners or affiliate trackers.

4. **Categorization**:
   - Add your entry to the most appropriate existing section. If you believe a new section is warranted, open an issue first to discuss it.

---

### Submitting a Pull Request

1. Fork the repository.
2. Create a feature branch: `git checkout -b add/my-awesome-resource`.
3. Make your additions following the formatting standards.
4. Commit your changes with a clear message: `git commit -m "docs: add <Resource Name> to <Section>"`.
5. Push to your fork: `git push origin add/my-awesome-resource`.
6. Open a Pull Request against the `main` branch with a brief rationale for why the resource belongs in this list.
